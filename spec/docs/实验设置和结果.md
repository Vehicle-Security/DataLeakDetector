## 实验1：单个动作识别准确率

### Table 1：单步外发动作识别

实验目的：测试 ScreenGuard 对桌面端和浏览器端单步外发动作的识别能力。

- 数据集：stage1内直接外发样本，覆盖 8 类外发渠道。

- 实验设置：采用 few\-shot Prompt，每类仅列举少量代表性应用，其余应用不进行逐一枚举。

- 指标：按 8 种外发类别统计 Precision、Recall 和 F1；系统输出 No Detection 时，记为对应真实类别的 FN。

> 能够证明：ScreenGuard 在 8 类、样本上的单步外发动作识别表现。
> 
> 



### Table 2：隐藏操作识别

实验目的：测试 ScreenGuard 对转换、提取、屏幕采集和外设转移等操作的识别能力，以及能否识别操作产生的派生载体或目标位置。

- 数据集：stage2内，覆盖 5 类操作族及其下属细粒度操作。

- 指标：操作识别成功率，以及派生载体 / 目标识别准确率。

- 统计方式：按 5 个一级操作族汇总，但成功判定依据具体二级操作是否识别正确。

> 能够证明：ScreenGuard 能否识别泄露链中的非直接外发操作，并恢复敏感内容经操作后形成的派生载体或目标。
> 
>

### Table 4：多步外发链路还原

table4：测试 ScreenGuard 对多步外发案例的链路还原能力，并与可输出链路的 baseline 对比。

- 可计算指标：Full Path Acc\.、Step Rec\. 、Sink Acc\.。

- 其中 Full Path Acc\. 表示完整泄露链是否全部还原正确；Step Rec\. 表示真实泄露链中的关键步骤，有多少被系统正确还原；Sink Acc\. 表示最终外发目的地是否识别正确。

- 数据集样本：完整外发案例30个，未知案例15个。

> ai: 统计方式建议使用 n/N \(%\)，因为样本规模较小，只写百分比会显得过于精确。
> 
> 这个表主要证明：ScreenGuard 不只是能判断案例是否泄露，还能否还原敏感数据从原始文件到中间载体再到最终外发目的地的传播过程。
