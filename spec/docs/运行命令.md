## 3. Release Mode

固定全量起点是 `spec\data\nas_samples`。`--case-root` 会递归发现其中所有同时包含 `logs` 和 `video` 的 case；当前共 309 个。

### Neo4j 预热

先启动 Neo4j，并用单 worker 顺序导入所有日志。预热不启用视觉模型，不消耗 VLM 配额；后续全量运行会复用相同 case/log 指纹，避免并发导入超时。

```powershell
.\tools\start_neo4j.ps1

$python = ".\.venv\Scripts\python.exe"
$env:DLD_NEO4J_REUSE_IMPORT="1"
$env:DLD_NEO4J_LOG_MINER_BATCH_SIZE="500"

& $python tools\warm_neo4j.py `
  --case-root "spec\data\nas_samples" `
  --output "artifacts\all_data_neo4j_warmup\progress.json"
```

终端会显示当前 case 和 `batch=... events=.../...`；实时状态写入 `artifacts\all_data_neo4j_warmup\progress.json`。预热结束后确认其中 `failed_cases=0`。

### 全量 Release 矩阵

所有 309 个 case 从同一固定根目录运行。九个策略/grid 组合顺序执行；每个组合内部 4 个 case 并行准备，VLM 仍严格限制为 Coding 10 路加 Token 10 路。全量 VLM 批处理强制使用内存日志挖掘，避免本地 Neo4j 在并发查询时出现 Bolt 超时。

```powershell
$python = ".\.venv\Scripts\python.exe"
$strategies = @("direct_keyframes", "ocr_all", "ocr_triage")
$grids = @(1, 2, 3)

& $python main/run_e2e.py `
  --case-root "spec\data\nas_samples" `
  --case-workers 4 `
  --release `
  --release-vlm-strategies $strategies `
  --release-vlm-grids $grids `
  --output-dir "artifacts\all_data_release_matrix" `
  --no-neo4j-log-miner `
  --vision `
  --vision-mode hybrid `
  --max-vlm-frames -1 `
  --vlm-workers 10 `
  --vlm-fast-dispatch
```

该命令会执行 `309 x 3 x 3` 个 case/组合分析，实际耗时和 VLM 成本较高。输出仅保留一份：

```text
artifacts\all_data_release_matrix\release_matrix_report.json
```

运行期间终端会输出当前策略组合、已开始的 case，以及每个完成或失败的 case。实时状态会原子写入：

```text
artifacts\all_data_release_matrix\release_progress.json
```

其中 `variant` 表示当前第几个策略/grid 组合，`running_cases` 是正在处理的 case，`queued_cases` 是尚未开始的数量，`last_case` 和 `recent_cases` 用于查看刚完成或失败的 case。

## 5. 快速终止运行

当全量任务无法及时响应键盘中断时，先终止本项目的 `run_e2e.py` 进程及其子进程：

```powershell
$all = Get-CimInstance Win32_Process
$ids = [System.Collections.Generic.List[int]]::new()

$all |
  Where-Object {
    $_.Name -match "^python.*\.exe$" -and
    $_.CommandLine -match "(?i)(^|[\s\"])main[\\/]run_e2e\.py([\s\"]|$)"
  } |
  ForEach-Object { [void]$ids.Add([int]$_.ProcessId) }

do {
  $children = $all | Where-Object {
    $ids.Contains([int]$_.ParentProcessId) -and -not $ids.Contains([int]$_.ProcessId)
  }
  $children | ForEach-Object { [void]$ids.Add([int]$_.ProcessId) }
} while ($children)

$ids | Sort-Object -Descending | ForEach-Object {
  Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue
}
```

紧急情况下可以直接终止全部 Python 进程，但这会同时停止无关的测试、服务和脚本：

```powershell
Get-Process python, python3 -ErrorAction SilentlyContinue | Stop-Process -Force
```
