# 运行命令

所有命令都在仓库根目录执行：

```powershell
cd D:\Projects\Job\DataLeakDetector
python --version
```

当前视觉链路只有一种策略：`direct keyframes`。流程是日志挖掘可疑窗口、按画面变化抽关键帧、把关键帧直接交给 VLM、再进入事件关联和 Datalog 推理。没有 OCR、ROI、OCR triage、release matrix，也不需要 `.venv`。

## 1. 环境准备

安装项目和测试依赖：

```powershell
python -m pip install -e ".[dev,vision]"
python -c "import cv2, neo4j, pytest; print('runtime ok')"
```

VLM 使用 OpenAI-compatible 接口。按需在 `.env` 或当前 PowerShell 里配置：

```powershell
$env:DLD_VLM_USE_CODING_PLAN = "1"
$env:DLD_VLM_CODING_BASE_URL = "https://coding.dashscope.aliyuncs.com/v1"
$env:DLD_VLM_CODING_API_KEY = "<your-key>"
```

常用并发：

```powershell
$env:DLD_VLM_WORKERS = "4"
$env:DLD_VLM_FAST_DISPATCH = "1"
```

Neo4j 只作为可选日志挖掘后端，不写回检测报告图。默认不配置 Neo4j，流水线直接使用内存日志挖掘。临时启用 Neo4j 日志挖掘：

```powershell
python main/run_e2e.py `
  --case "spec\data\nas_samples\stage1\1-email-fastmail-1" `
  --output-dir "artifacts\debug_neo4j_log_miner" `
  --vision `
  --neo4j-log-miner
```

也可以写到本地 `.env`：

```powershell
DLD_NEO4J_LOG_MINER=1
DLD_NEO4J_URI=bolt://localhost:7687
DLD_NEO4J_USER=neo4j
DLD_NEO4J_PASSWORD=data-leak-detector
DLD_NEO4J_DATABASE=neo4j
```

## 2. 快速自检

不调用真实模型，只检查日志挖掘、抽帧、VLM 请求构造和报告输出是否跑通：

```powershell
$env:DLD_VLM_DRY_RUN = "1"
python main/run_e2e.py `
  --case "spec\data\nas_samples\stage1\1-email-fastmail-1" `
  --output-dir "artifacts\smoke_direct_only" `
  --vision `
  --max-vlm-frames 2 `
  --vlm-workers 1
Remove-Item Env:\DLD_VLM_DRY_RUN
```

重点产物：

```text
artifacts\smoke_direct_only\<report_id>\keyframes_raw\
artifacts\smoke_direct_only\<report_id>\keyframes_vlm_input\
artifacts\smoke_direct_only\<report_id>\vlm_request.json
artifacts\smoke_direct_only\<report_id>\vlm_response.json
artifacts\smoke_direct_only\<report_id>\leak_paths.json
```

## 3. Debug 单样本

Debug 模式会在每个样本目录下保留 VLM 输入、请求和返回，适合定位漏判/误判：

```powershell
python main/run_e2e.py `
  --case "spec\data\nas_samples\stage1\1-email-fastmail-1" `
  --output-dir "artifacts\debug_single" `
  --vision `
  --max-vlm-frames -1 `
  --vlm-grid-size 2 `
  --vlm-workers 4 `
  --vlm-fast-dispatch
```

## 4. Release 全量

Release 模式默认启用 direct keyframes、继承父目录 groundtruth、关闭非 VLM 证据合并，并且不在每个 case 下写 VLM 请求/返回明细。

预处理只抽 keyframes，不调用 VLM：

```powershell
$runDir = "artifacts\full_release_direct"
python main/run_e2e.py `
  --case-root "spec\data\nas_samples" `
  --case-workers 2 `
  --release `
  --release-precompute-only `
  --output-dir $runDir `
  *> "$runDir\precompute.log"
```

VLM 阶段：

```powershell
$runDir = "artifacts\full_release_direct"
python main/run_e2e.py `
  --case-root "spec\data\nas_samples" `
  --case-workers 40 `
  --release `
  --output-dir $runDir `
  --vlm-grid-size 2 `
  --vlm-workers 4 `
  --vlm-fast-dispatch `
  *> "$runDir\vlm.log"
```

Release 汇总文件：

```text
artifacts\full_release_direct\release_report.json
artifacts\full_release_direct\release_comparison.json
artifacts\full_release_direct\release_progress.json
artifacts\full_release_direct\release_precompute_progress.json
```
