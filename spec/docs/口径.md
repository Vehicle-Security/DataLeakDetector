对，现在实现里其实有三套概念，要分开看：

**1. 初始敏感文件**
当前“初始敏感文件”来自两处：

- `groundtruth.json`
- 命令行显式传入的 `--sensitive-file`

入口在 [datasets.py](/d:/Projects/Job/DataLeakDetector/main/data_leak_detector/datasets.py)：

```python
sensitive = set(extract_sensitive_sources(groundtruth_file))
```

真正提取逻辑在 [sensitivity.py](/d:/Projects/Job/DataLeakDetector/main/data_leak_detector/sensitivity.py)。默认会从 `groundtruth.json` 里找这些字段：

```text
sensitive_file_path
sensitive_file
sensitive_path
source_file
```

也可以通过 `.env` 改：

```text
DLD_SENSITIVE_SOURCE_FIELDS=...
DLD_SENSITIVE_SOURCE_JSON_PATHS=...
DLD_SENSITIVE_SOURCE_REGEXES=...
```

注意：默认不会从日志里“猜”初始敏感文件。`EventCorrelatorConfig.infer_sensitive_from_logs` 默认是 `False`，这是为了避免传统关键词规则把一堆文件误判成敏感源。

但这里有个当前实现的边界：如果 `groundtruth.json` 里把某个衍生文件也写进了 `sensitive_file_path`，当前提取器会把它当初始敏感文件。严格说，后面应该再加一个 operation-aware 的敏感源策略，例如只把“原始打开/源文件”字段当初始源，`潜在隐藏行为` 里产生的文件只进入派生推理。

**2. 派生文件**
派生文件不是初始表里写进去的，而是在 [correlator.py](/d:/Projects/Job/DataLeakDetector/main/data_leak_detector/event_correlator/correlator.py) 的 `_build_lineage()` 里推出来。

它主要靠三种信号：

第一种：日志 metadata 里有显式源文件。

```python
original = original_file_from_metadata(event.raw)
if original and self._resolve_original(original, sensitive_files, lineage):
    lineage.add(event.file_path, original)
```

比如日志里有：

```json
{
  "file_path": "C:/tmp/customer_salary_part1.xlsx",
  "source_file": "C:/Users/alice/Documents/customer_salary.xlsx"
}
```

如果 `source_file` 能追溯到初始敏感文件，就建立：

```text
customer_salary_part1.xlsx -> customer_salary.xlsx
```

第二种：同一进程最近操作过敏感文件，随后发生了复制、导出、压缩、转换、截图、录屏等 transfer 行为。

```python
if event.file_path and contains_any(text, TRANSFER_TOKENS):
    source = original or guess_source_by_stem(...) or last_sensitive_by_process.get(process_key, "")
```

这里会检查 `source` 是否真的能追溯到初始敏感文件，不能的话就丢掉，避免“看起来像敏感词”的普通文件污染 lineage。

第三种：文件名 stem 近似。

比如已知敏感源是：

```text
customer_salary.xlsx
```

后面出现：

```text
customer_salary_part1.xlsx
```

`guess_source_by_stem()` 会认为它可能来自原文件。但它仍然要通过 `_resolve_original()` 校验，不能凭空造敏感源。

最终 lineage 保存在 [lineage.py](/d:/Projects/Job/DataLeakDetector/main/data_leak_detector/event_correlator/lineage.py)：

```text
derived_file -> source_file
```

推理时会变成 Datalog 的 `TransferFile`：

```text
OpenFile(source)
TransferFile(source -> derived)
LeakFile(derived)
```

然后 [engine.py](/d:/Projects/Job/DataLeakDetector/main/data_leak_detector/leak_reasoner/engine.py) 做污点传播。如果上传的是派生文件，只要链路能追到敏感源，也会推出泄密路径。
