### 第二批优化（全新实现）

#### 4. 基于行为特征的帧打分系统 ⭐ 核心创新

**位置**: `01-FrameAnalyzer/frame_scorer.py`

**设计原则**:

1. ✅ **不硬编码软件名** - 基于通用行为模式
2. ✅ **轻量级** - 比VLM快100倍（0.1秒 vs 5秒）
3. ✅ **可解释** - 每个分数都有breakdown
4. ✅ **可配置** - 不同场景不同权重

**核心特征**:

- **时序特征** (0-30分): 高斯衰减，越接近预期时间分数越高
- **视觉变化** (0-40分): 适度变化（5-30%）得分最高
- **OCR关键词** (0-50分): 强completion关键词50分，weak 35分
- **敏感内容** (0-25分): 敏感文件名出现在画面中
- **行为模式** (0-50分加成): 检测到消息发送/文件上传等模式

**行为模式检测器** (通用，不依赖软件名):

- `MessageSentDetector`: 检测消息发送（微信、钉钉、Telegram等通用）
- `FileUploadDetector`: 检测文件上传（网盘通用）
- `ContentPublishDetector`: 检测内容发布

**测试**: ✅ 9/9通过

**预期效果**:

- 关键帧命中率: 15% → 50-70% (提升**3-5倍**)
- VLM有效调用率提升3-5倍
- Completion帧覆盖率: 15% → 60-80%

**示例**:

```python
# 高分帧示例
Frame(t=10.5s, score=160.0):
  - temporal: 30分 (刚好在预期时间)
  - visual: 20分 (适度变化15%)
  - ocr: 50分 (检测到"发送成功")
  - sensitive: 25分 (敏感文件名可见)
  - pattern_message_sent: 35分 (检测到消息发送模式)
  - 总分: 160分，置信度: 0.82
```
