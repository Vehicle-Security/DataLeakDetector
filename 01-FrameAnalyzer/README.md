# 01-FrameAnalyzer

该目录对应新三模块架构中的模块 1。

## 当前状态

模块 1 目前已经对外提供稳定的 `segments` 数据契约，供 `EventCorrelator` 消费。

当前真实情况：

- 对外输出 schema 已按新架构收口
- `full` 模式下的视频/OCR/VLM 分析链路是真实运行的
- 内部后端仍复用了迁移后的旧视觉栈
- 对外暴露的 segment id、资源字段和元数据已经按新管线规范化

## 当前职责

- 接收视频路径、录屏起始时间、搜索窗口和目标关键词
- 运行现有 OCR/VLM 支撑的视觉分析链路
- 将后端 `events` 转换为新架构可消费的结构化 `segments`
- 将可复用缓存写入 `output/frame_cache`
- 默认关闭 debug 帧导出，仅在显式环境变量开启时才落盘

## 当前限制

该模块还不是旧视觉引擎的完整重写版。
当前更准确的描述应是：

- 基于迁移后视觉后端的生产化适配层
- 对外提供了适配新 `01 -> 02 -> 03` 管线的干净输出契约

这意味着主链路已经可以端到端运行，但模块 1 仍保留一定的内部历史实现债务。
