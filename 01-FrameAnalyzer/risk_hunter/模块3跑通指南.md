# 模块3跑通指南（RiskHunter）

这份指南以当前仓库代码为准，目标是让你从 0 到 1 跑通模块3。

## 1. 安装依赖

模块3会调用模块2和模块1，所以依赖要一起装。

```bash
cd /home/dxy/Projects/DataLeakDetector/01-FrameAnalyzer/risk_hunter
pip install -r ../file_tracker/requirements.txt
pip install opencv-python pillow easyocr torch torchvision
```

说明：
- 前一行安装 LangGraph / LangChain / dotenv 等核心依赖。
- 后一行安装模块1视频分析需要的依赖。

## 2. 配置大模型 API

在项目根目录创建 `.env` 文件，并配置你的 API 密钥：
建议放在 DataLeakDetector 根目录（也可放在 01-FrameAnalyzer/risk_hunter和01-FrameAnalyzer 目录）。

文件路径示例：
- /home/dxy/Projects/DataLeakDetector/.env

内容如下：

```env
VL_MODEL_NAME=qwen3.7-plus
MODEL_NAME=qwen2-vl-72b-instruct
OPENAI_BASE_URL=https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
OPENAI_API_KEY=你的API_KEY
TEMPERATURE=0.01
```

确保 `.env` 中的 `OPENAI_API_KEY` 已配置。

## 3. 配置检测参数

### 3.1 敏感文件和黑白名单

修改文件：
- 01-FrameAnalyzer/risk_hunter/upload_detection_config.py

你需要配置（如果缺少的话）：
- sensitive_files（敏感文件路径，注意还需在斜杠\前加上转义字符\）
- blacklist_apps
- whitelist_apps

### 3.2 本次运行目标记录

修改文件：
- 01-FrameAnalyzer/risk_hunter/run_upload_detection.py

关键参数：
- record_id = 43（改成你要跑的会话,eg:"1-email-163email-1"）
- search_duration = 30（模块1视频搜索窗口，单位秒）

## 4. 检查输入数据目录

模块3默认读取：

```text
01-FrameAnalyzer/risk_hunter/records/{record_id}/
├── INDEX.md
├── key_events/key_events_*.json
└── video/*.mp4 或 *.mov
```

records目录是旧数据集目录，请新建目录recordings/stage1（阶段一数据集）、stage2（阶段二数据集）、stage4（阶段四数据集），并将数据集放在该目录下，并修改模块3以下文件：

修改文件：
- 01-FrameAnalyzer/risk_hunter/run_upload_detection.py

关键参数：
- base_path = f"records/{record_id}"（修改records为你的数据集目录如"recordings/stage2/{record_id}"）


注意：
- 缺少任一项都会直接退出并打印错误。
- 代码支持 mp4 和 mov。

## 9. 常见报错与解决

### 9.1 ModuleNotFoundError: No module named upload_detection_config

原因：导入名与文件名不一致。

检查：
- 01-FrameAnalyzer/risk_hunter/upload_detection_config.py 是否存在
- 01-FrameAnalyzer/risk_hunter/upload_detector_nodes.py 和 01-FrameAnalyzer/risk_hunter/run_upload_detection.py 是否写成：

```python
from upload_detection_config import config
```

### 9.2 Recursion limit of 25 reached

原因：worklist 事件较多，超过 LangGraph 默认递归限制。

处理：在 `run_upload_detection.py` 中调大：

```python
graph_config = {"recursion_limit": 100}
```

如果事件更多，可继续调大到 200。

### 9.3 API 调用失败 / 401 / 403

检查：
- OPENAI_API_KEY 是否正确
- OPENAI_BASE_URL 是否与你使用的平台匹配
- 模块1里是否还在使用过期写死 key
