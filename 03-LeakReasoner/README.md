# 03-LeakReasoner

该目录对应新三模块架构中的模块 3。

## 当前职责

`LeakReasoner` 当前负责：

- 消费 `CorrelationBundle`
- 将关联后的结构化证据转换为推理事实
- 将上传候选评分并收敛为 `RiskCase`
- 输出稳定的案件与证据结果

## 当前状态

该模块已经位于 `full` 验收主链路中。

当前可以确认的事实：

- 它已经不是纯设计占位符
- 对当前验收样例，能够稳定生成 `RiskCase`
- 当前仍采用轻量级进程内推理流程
- Datalog bridge 已接入，但最终案件生成仍主要由确定性评分逻辑驱动

## 当前限制

该模块当前更准确的描述应是：

- 新三模块管线中的可运行确定性推理器
- 还不是旧模块 3 目标设计里那种完全吸收式的规则引擎架构
